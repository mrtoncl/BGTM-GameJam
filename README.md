# BGTM-GameJam

## Project Overview

**BGTM-GameJam** is a game project developed in C# as part of a game jam event. The repository contains the full source code of the game, along with necessary assets and scripts, allowing others to review and learn from the project’s structure and logic.

---

## Features

- **Complete C# Game Source Code**  
  Designed for Unity or compatible C# game frameworks.
- **Game Jam Scope**  
  Developed in a short time frame for rapid prototyping and creativity.
- **Modular Code Structure**  
  Logical separation of scripts, assets, and core mechanics.
- **Educational Reference**  
  Useful for those interested in game jams, rapid game development, or C# game programming.

---

## Contents

The repository typically contains:

- C# scripts for game mechanics and logic
- Game assets (artwork, audio, prefabs, etc.)
- Configuration or scene files
- Documentation or comments explaining key structures

---

## Getting Started

### Prerequisites

- Unity (recommended version specified in project settings) or compatible C# IDE
- C# 7.0 or later

### Running the Project

1. Clone the repository:
    ```sh
    git clone https://github.com/mrtoncl/BGTM-GameJam.git
    cd BGTM-GameJam
    ```

2. Open the project in Unity or your C# IDE.

3. Press Play to run the game.
